# Checkpoint: proxy observability dashboard

React, Vite and Recharts dashboard for the microservices monitoring system with a Logging Proxy.

Backend, full documentation and Proxy pattern theory: [BACKEND-PROXY](https://github.com/ssantivr/BACKEND-PROXY)

```bash
npm install
cp .env.example .env
npm run dev
```

`VITE_API_URL` is the backend URL.
